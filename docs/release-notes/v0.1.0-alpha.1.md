# v0.1.0-alpha.1 — Release notes draft

This is a draft for the intended alpha version. It has no release date and does not assert that a source tag, prerelease, or asset has been published.

## Intended contents

- Linux amd64 asset `auditor_v0.1.0-alpha.1_linux_amd64`, `checksums.txt`, and Apache-2.0 `LICENSE`.
- Read-only audit and comparison commands with category, safe text, and JSON output.
- Evidence-backed OpenCode `1.18.27` singular legacy scalar `permission`: explicit `read`, `edit`, and `bash` only.

The source tag, embedded binary version, and asset filenames must all match `v0.1.0-alpha.1` before publication. Follow [installation](../installation.md) for qualified download, checksum, and smoke instructions.

## Evidence and limitations

Checked-in [OpenCode evidence](../../support/evidence.md) defines the support boundary. [`scripts/test_release.py`](../../scripts/test_release.py) checks the local Linux amd64 package, checksum, license, version/help, and supported-fixture audit; it is not evidence that a public asset is reachable.

This is static configuration analysis, not runtime policy enforcement, a security guarantee, or compliance certification. Claude Code, additional platforms, package managers, signing, provenance, and general OpenCode compatibility are out of scope. A checksum is not a signature.

## Publication and follow-up

Maintainers publish only after the release checks and human gates are complete; the GitHub Release is the canonical availability record. If an artifact or claim is wrong, withdraw or correct the prerelease and its notes without changing user configuration.

## Post-release pilot

A post-release pilot may collect sanitized feedback after publication. It is not a publication gate and is not evidence of adoption, usage, security effectiveness, production readiness, or ecosystem acceptance.
