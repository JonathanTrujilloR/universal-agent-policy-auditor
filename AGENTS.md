# Project agent instructions

## Pull request preparation

Load `.pi/skills/work-unit-pr-policy/SKILL.md` before preparing, reviewing, or opening a pull request for this repository.

That project skill supersedes global `branch-pr` only where `branch-pr` requires a closing keyword on every PR: intermediate bounded PRs use `Refs #N`, and exactly the final Work Unit PR closes the approved issue. All other applicable `branch-pr` rules remain active.
